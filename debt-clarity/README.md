# BLUE Debt Clarity

Founder and decision-maker: Marian Meller. A German pilot for people trying to understand debt collection letters.

- [Three fictional case cards (PDF)](Case-cards.pdf)
- [One-page pilot invitation for advice centres (PDF)](Pilot-invitation.pdf)
- [Offline interactive prototype](index.html) — download and open in a browser to choose and print a case.

The cards trace each claimed amount to the supplied documents and give the reader a specific question for an adviser. We invite a debt advice centre to review the three fictional examples in a free 30-minute session. The demonstration accepts no client documents.
